# WorkWithAI
Repo untuk eksperimen dan aplikasi kecil yang dibuat dengan bantuan AI.

## Aplikasi

- [Papan Proyek dan Kebiasaan Harian](papan-proyek-kebiasaan.html) — aplikasi satu halaman untuk mencatat tugas, tenggat, prioritas, dan kebiasaan mingguan. Data disimpan secara lokal di browser.
- [Planner Harian AI](planner-harian.html) — aplikasi satu halaman untuk mengelola tugas harian, prioritas, dan fokus kerja dengan penyimpanan lokal di browser.
- [Random Joke Generator](random-joke-generator.html) — generator lelucon acak berbasis API publik (icanhazdadjoke).
- [Kumpulan Prompt AI Lintas Industri](kumpulan-prompt-ai-lintas-industri.md)
- [Demo Kartu Ide](tes-web-sederhana.html)
- [Tracker Keuangan Pribadi](tracker%20keuangan%20pribadi.html)

Buka file HTML langsung di browser. Tidak perlu instalasi atau server.
